# コーチ明細 自動発行（PDF）

コーチシステム（Googleスプレッドシート）に、**コーチ明細をボタンひとつでPDF発行する機能**を追加するためのスクリプトです。
既存の「振込CSV」を作るときに使っている集計データを、そのまま明細PDFの元データとして利用します。

## 何ができる？

- スプレッドシートのメニュー **「コーチ明細」→「明細を発行（PDF）」** を押すと
- コーチ **1人につき1枚のPDF明細** を作成し
- Googleドライブの **`コーチ明細 / 2026年08月 / 山田太郎.pdf`** のように月フォルダへ自動保存します。

明細に載る内容（例）:

> 対象月／コーチ名／各明細行（日付・内容・単価・件数・金額）／小計／控除（任意）／**振込予定額**／振込予定日（任意）

## 導入手順

1. コーチシステムのスプレッドシートを開く
2. 上部メニュー **「拡張機能」→「Apps Script」** を開く
3. `コーチ明細発行.gs` の中身を全部コピーして貼り付け、**保存**（ディスクのアイコン）
4. スクリプト先頭の **`CONFIG`** を自分のシートに合わせて設定（下記）
5. スプレッドシートのタブに戻って **ページを再読み込み**
6. メニューに **「コーチ明細」** が出るので **「明細を発行（PDF）」** を実行
7. 初回だけ Google の権限確認が出ます → 自分のアカウントで許可
8. 対象月（例: `2026年08月`）を入力 → 完了。最後に保存先フォルダのURLが表示されます。

## 設定（CONFIG）

```js
var CONFIG = {
  DATA_SHEET_NAME: '明細データ',   // ← 明細の元データがあるシート名に変更
  HEADER_ROW: 1,                    // ← 見出し行の行番号

  COL: {                            // ← 実際の「見出しの文字」に合わせる（列は自動判定）
    coachName: 'コーチ名',          //    必須：この列でコーチごとにまとめる
    date:      '日付',
    content:   '内容',
    unitPrice: '単価',
    quantity:  '件数',
    amount:    '金額',              //    必須：合計に使う金額列
    deduction: '',                  //    控除がある場合は列名を入れる（例: '控除'）
    note:      ''                   //    備考列があれば（例: '備考'）
  },

  PARENT_FOLDER_ID: '',             // ← 保存先の親フォルダID（空ならマイドライブ直下）
  SHOP_NAME: 'anela',
  PAYMENT_DATE_A1: '',              // ← 振込予定日を1セルから取るなら 'シート名!B2' 等
  CURRENCY: '¥'
};
```

### ポイント

- **列は「見出しの名前」で自動判定**します。列の順番が変わっても、見出しの文字さえ合っていれば動きます。
- 使わない項目は **`''`（空文字）** にすれば明細に出しません（必須は `coachName` と `amount`）。
- 元データが **1行＝1レッスン（1明細行）** の形なら、コーチ名でまとめて自動集計します。
  すでに **1行＝1コーチの合計** になっている場合も、そのまま1行として明細化されます。

## よくある確認事項

- **保存先を決まったフォルダにしたい** → そのフォルダを開き、URLの `.../folders/XXXX` の `XXXX` を `PARENT_FOLDER_ID` に設定。
- **同じ月に再発行したら？** → 同名PDFは上書き（古いものはゴミ箱へ）します。
- **各コーチへ自動メール送信もしたい** → 現在は「ドライブ保存」まで。メール送信は後から追加可能です（本人メール列を用意すれば拡張できます）。

必要になったら、その時のシート構成を教えていただければ調整します。
