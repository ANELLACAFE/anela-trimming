# 工賃明細 自動発行（PDF・全員分1ファイル）

工賃システム（Googleスプレッドシート）に、**工賃明細をボタンひとつでPDF発行する機能**を追加するためのスクリプトです。
既存の「振込CSV」を作るときに使っている集計データを、そのまま明細PDFの元データとして利用します。

## 何ができる？

- スプレッドシートのメニュー **「工賃明細」→「明細を発行（PDF・全員分1ファイル）」** を押すと
- 全利用者分の明細を **1つのPDFファイル** にまとめて作成し（**1名＝1ページ**、改ページで区切り）
- 指定した **Googleドライブのフォルダ** へ保存します。

印刷すれば、そのまま1ページずつ各利用者様へ配布できます。

明細に載る内容（例）:

> 対象月／利用者名／各明細行（日付・内容・単価・件数・金額）／小計／控除（任意）／**振込予定額**／振込予定日（任意）

## 導入手順

1. 工賃システムのスプレッドシートを開く
2. 上部メニュー **「拡張機能」→「Apps Script」** を開く
3. `工賃明細発行.gs` の中身を全部コピーして貼り付け、**保存**（ディスクのアイコン）
4. スクリプト先頭の **`CONFIG`** を自分のシートに合わせて設定（下記）
5. スプレッドシートのタブに戻って **ページを再読み込み**
6. メニューに **「工賃明細」** が出るので **「明細を発行（PDF・全員分1ファイル）」** を実行
7. 初回だけ Google の権限確認が出ます → 自分のアカウントで許可
8. 対象月（例: `2026年08月`）を入力 → 完了。最後に保存先PDFのURLが表示されます。

## 設定（CONFIG）

```js
var CONFIG = {
  DATA_SHEET_NAME: '明細データ',   // ← 明細の元データがあるシート名に変更
  HEADER_ROW: 1,                    // ← 見出し行の行番号

  COL: {                            // ← 実際の「見出しの文字」に合わせる（列は自動判定）
    userName:  '利用者名',          //    必須：この列で利用者ごとにまとめる（1名1ページ）
    date:      '日付',
    content:   '内容',
    unitPrice: '単価',
    quantity:  '件数',
    amount:    '金額',              //    必須：合計に使う金額列
    deduction: '',                  //    控除がある場合は列名を入れる（例: '控除'）
    note:      ''                   //    備考列があれば（例: '備考'）
  },

  SAVE_FOLDER_ID: '',               // ← 保存先フォルダのID（この中に1つのPDFを保存）
  SHOP_NAME: 'anela',
  PAYMENT_DATE_A1: '',              // ← 振込予定日を1セルから取るなら 'シート名!B2' 等
  CURRENCY: '¥'
};
```

### 保存先フォルダの指定方法（SAVE_FOLDER_ID）

利用者様が用意したフォルダに保存する場合：

1. そのフォルダをブラウザで開く
2. URL が `https://drive.google.com/drive/folders/XXXXXXXX` のようになっているので、
3. 末尾の **`XXXXXXXX` の部分をコピー**して `SAVE_FOLDER_ID` に貼り付け

※ 空のままだと、マイドライブ直下に「工賃明細」フォルダを自動作成してそこへ保存します。

### ポイント

- **列は「見出しの名前」で自動判定**します。列の順番が変わっても、見出しの文字さえ合っていれば動きます。
- 使わない項目は **`''`（空文字）** にすれば明細に出しません（必須は `userName` と `amount`）。
- 元データが **1行＝1明細行** の形なら、利用者名でまとめて自動集計します。
  すでに **1行＝1利用者の合計** になっている場合も、そのまま1行として明細化されます。
- 出力は **全員分が1つのPDF**。**1名につき1ページ**になるよう改ページを入れています。

## よくある確認事項

- **同じ月に再発行したら？** → 同じ保存先の同名PDF（`工賃明細_2026年08月.pdf`）は上書き（古いものはゴミ箱へ）します。
- **印刷は？** → PDFを開いてそのまま印刷すれば、1ページ＝1名で出力されます。
