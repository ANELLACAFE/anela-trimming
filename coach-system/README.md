# 工賃明細 自動発行（PDF・全員分1ファイル）

就労継続支援B型「工賃システム」（Googleスプレッドシート）に、**工賃明細をボタンひとつでPDF発行する機能**を追加するスクリプトです。
毎月の工賃計算の結果がたまる **「工賃履歴」シート** を、そのまま明細PDFの元データとして利用します。

## 何ができる？

- スプレッドシートのメニュー **「工賃明細」→「明細を発行（PDF・全員分1ファイル）」** を押す
- **対象月を番号で選ぶ**（履歴にある月が一覧で出ます）
- 選んだ月の全利用者分の明細を **1つのPDFファイル** にまとめて作成（**1名＝1ページ**、改ページ区切り）
- 指定した **Googleドライブのフォルダ** へ保存します。

印刷すれば、そのまま1ページずつ各利用者様へ配布できます。

明細に載る内容:

> 事業所名／発行日／対象月／利用者氏名／作業時間／時給／**工賃（振込予定額）**

※ B型工賃は非雇用の「雑所得」で源泉・社保・雇用保険の天引きがないため、**工賃＝振込予定額**として表示します（控除欄なし）。

## 元データ（工賃履歴シート）の前提

工賃システムが自動で作る「工賃履歴」シートの見出しに合わせています。

| 計算日 | 対象期間 | 氏名 | 受給者証番号 | 作業時間 | 時給(円) | 工賃(円) |
|---|---|---|---|---|---|---|

- **対象期間**：この列の値で「対象月」を選びます（1件＝1月分）。
- **氏名**：利用者ごとにまとめて1名1ページにします。
- **工賃(円)**：振込予定額として表示します。
- 列は **見出しの文字で自動判定**するので、列の順番が変わっても見出しさえ合っていれば動きます。

## 導入手順

1. 工賃システムのスプレッドシートを開く
2. 上部メニュー **「拡張機能」→「Apps Script」** を開く
3. ファイル一覧の **「＋」→「スクリプト」** で新しいファイルを追加し、`工賃明細発行.gs` の中身を全部コピーして貼り付け、**保存**（ディスクのアイコン）
   - ※ 既存の `コード.gs` は消さず、**別ファイルとして追加**します
4. スクリプト先頭の **`CONFIG`** の `SAVE_FOLDER_ID` と `SHOP_NAME` を設定（下記）
5. **メニューを1行追加**：既存の `コード.gs` の `onOpen` に、下の1行を足す（②の行のすぐ下がおすすめ）

   ```js
   .addItem('② 振込CSVを作る（GMOあおぞら）', 'makeTransferCsv')
   .addItem('③ 工賃明細を発行（PDF・全員分）', 'issueWageStatements')  // ← この行を追加
   ```

   > **なぜ？** `工賃明細発行.gs` に `onOpen` を書くと、`コード.gs` の `onOpen` と名前が重複し、メニューが片方しか出ません。そのため既存メニュー（工賃システム）に統合します。

6. スプレッドシートのタブに戻って **ページを再読み込み**
7. メニュー **「工賃システム」→「③ 工賃明細を発行（PDF・全員分）」** を実行
8. 初回だけ Google の権限確認が出ます → 自分のアカウントで許可
9. 対象月を番号で選ぶ → 完了。最後に保存先PDFのURLが表示されます。

## 設定（CONFIG）

```js
var CONFIG = {
  DATA_SHEET_NAME: '工賃履歴',      // 通常はこのまま（履歴シート）
  HEADER_ROW: 1,

  COL: {                            // 「工賃履歴」の見出しに合わせてあります（通常は変更不要）
    period:    '対象期間',          //   必須：この列の値で対象月を選ぶ
    userName:  '氏名',              //   必須：利用者ごとにまとめる（1名1ページ）
    workTime:  '作業時間',
    unitPrice: '時給(円)',
    amount:    '工賃(円)'           //   必須：振込予定額に使う金額列
  },

  SAVE_FOLDER_ID: '1zkZrQkcV7XGVxadShtPW6C_ob-In-YY-', // ← 保存先フォルダ（利用者勤怠＞工賃明細）
  SHOP_NAME: 'ANELLA CAFE 南浦和店', // ← 明細に印字する事業所名
  CURRENCY: '¥'
};
```

### 保存先フォルダの指定方法（SAVE_FOLDER_ID）

1. 保存したいフォルダをブラウザで開く
2. URL が `https://drive.google.com/drive/folders/XXXXXXXX` のようになっているので、
3. 末尾の **`XXXXXXXX` の部分をコピー**して `SAVE_FOLDER_ID` に貼り付け

※ 空のままだと、マイドライブ直下に「工賃明細」フォルダを自動作成してそこへ保存します。

## よくある確認事項

- **対象月はどうやって選ぶ？** → 実行時に「工賃履歴」にある対象期間の一覧が番号で出ます。番号を入力するだけ（空欄なら一番新しい月）。手入力しないので選び間違いが起きにくい設計です。
- **過去の月も出せる？** → はい。履歴に残っている月なら、いつでも選んで再発行できます。
- **同じ月に再発行したら？** → 同じ保存先の同名PDF（例 `工賃明細_2026年07月.pdf`）は上書き（古いものはゴミ箱へ）します。
- **1人が同じ月に複数行ある場合は？** → 工賃を合算して1ページにまとめます（通常は1名1行）。
- **印刷は？** → PDFを開いてそのまま印刷すれば、1ページ＝1名で出力されます。
