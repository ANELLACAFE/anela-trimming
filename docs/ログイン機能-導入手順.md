# ログイン機能（第1段階）導入手順

メールOTP（6桁コード）ログインで、飼い主様・わんちゃんの情報を次回から自動入力できるようにする機能です。
このドキュメントは **Supabase 側の設定** を順番に行うための手順書です。コード（`index.html` / `script.js` / `style.css`）は反映済みなので、下記の設定を行えば動作します。

> 全体像：**① SQLを流す → ② メールにコードを表示する設定 → ③ 動作テスト → ④（公開前に）外部メール設定**

---

## ① データベースの用意（SQLを実行）

1. Supabase ダッシュボードを開く
2. 左メニュー **SQL Editor** → **New query**
3. リポジトリ内の [`supabase/login_setup.sql`](../supabase/login_setup.sql) の中身を全部コピーして貼り付け
4. **Run** を押す

これで以下が作られます。

- `profiles`（飼い主様情報）／`pets`（わんちゃん情報）テーブル
- **RLS（行レベルセキュリティ）** … 本人の情報しか読み書きできない設定（プライバシー保護の要）
- `reservations` に `user_id` 列を追加（ログイン中の予約を紐づけ。既存の予約は影響なし）

> ⚠️ **必ずコードより先に、または同時に実行してください。** `reservations.user_id` 列が無い状態でログイン予約をすると、その予約だけエラーになります（ログインしない予約は従来通り動きます）。

---

## ② メールに「6桁コード」を表示する設定 ★重要

Supabase の初期設定では、ログインメールに **リンク** が入っています。**6桁コード方式**にするには、メール本文にコードを表示するよう変更します。

1. ダッシュボード左メニュー **Authentication** → **Emails**（または Email Templates）
2. **Magic Link** テンプレートを開く
3. 本文の中に **`{{ .Token }}`** を追加する（これが6桁コードになります）

例：本文を次のように書き換えます。

```html
<h2>ANELLA CAFE ご予約ログイン</h2>
<p>下記の確認コードを、予約ページの入力欄にご入力ください。</p>
<p style="font-size:28px; letter-spacing:6px; font-weight:bold;">{{ .Token }}</p>
<p>このコードの有効期限は10分です。心当たりがない場合はこのメールを破棄してください。</p>
```

4. 保存する

> 補足：`{{ .ConfirmationURL }}`（リンク）は残しても構いませんが、6桁コード運用なら無くても動きます。

### あわせて確認する設定（Authentication → Providers → Email）

- **Email** プロバイダが **有効（Enabled）** になっていること
- **Confirm email**（メール確認）が有効なこと（OTPログインの前提）
- （任意）**Authentication → Rate limits** で、コードの有効期限や送信間隔を調整可能
  - おすすめ：トークン有効期限を短め（例 600秒＝10分）に

---

## ③ 動作テスト

1. 予約ページを開く（キャッシュが残る場合はスーパーリロード）
2. 一番上の「ログイン（かんたん・任意）」で、自分のメールアドレスを入れて **確認コードを送る**
3. 届いたメールの6桁コードを入力して **ログイン**
4. 初回：フォームを普通に入力して予約 → 完了
5. もう一度ログインした状態でページを開き、**飼い主・わんちゃん情報が自動で入っていれば成功** 🎉

### RLS（プライバシー保護）の確認 — おすすめ

別のメールでもう1アカウント作り、そのアカウントでログインしても、
**他人の情報が一切表示されない**ことを確認してください。これがRLSが正しく効いている証明です。

---

## ④ 公開前に：外部メール（無料）へ切り替え

Supabase 標準メールは **テスト用（1時間2通・迷惑メールに入りやすい）** です。
**本番でお客様に使ってもらう前に**、無料の外部メールに切り替えると、コードが確実に届くようになります（費用はこの規模なら¥0）。

1. [Brevo](https://www.brevo.com/)（1日300通無料）または [Resend](https://resend.com/)（月3,000通無料）でアカウント作成
2. 送信元メール／ドメインの認証（SPF・DKIM）を設定
3. そのサービスの **SMTP情報**（ホスト・ポート・ユーザー・パスワード）を取得
4. Supabase ダッシュボード **Authentication → Emails → SMTP Settings** に入力し、**Enable Custom SMTP** をオン

> テスト段階（③まで）は標準メールのままで問題ありません。切り替えは公開直前の一度きりの作業です。

---

## この段階に「入れていないもの」（今後の候補）

安全・シンプルさを優先し、第1段階では次を意図的に見送っています。

- **ワクチン情報・証明書画像の自動入力** … 有効期限があるため、毎回ご確認いただく設計（安全・規約順守）
- **多頭飼い対応** … まず1頭でシンプルに。テーブルは将来の複数頭に対応済み
- **マイページ（予約履歴・変更・キャンセル）** … 第2段階
- **LINE / Google ログイン** … 第3段階

---

## 困ったときは

- **コードが届かない** → 迷惑メールを確認。標準メールは届きにくいので ④ の外部メール設定で解決
- **「6桁コードではなくリンクが届く」** → ② の `{{ .Token }}` 追加ができているか確認
- **ログイン予約だけ失敗する** → ① のSQL（特に `reservations.user_id` 列の追加）が実行済みか確認
- **自動入力されない** → 一度ログアウト→再ログイン。別アカウントで他人の情報が出ないのは正常（RLS）
